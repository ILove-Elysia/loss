# 《Lost Land》失落之岛 - 完整游戏策划案

---

## 第一章：项目立项概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《Lost Land》（失落之岛） |
| 游戏类型 | 3D俯视角生存建造冒险游戏 |
| 核心玩法 | 采集、合成、建造、探索、生存、战斗 |
| 目标平台 | Steam PC |
| 开发阶段 | Demo优先，EA阶段补全 |
| 开发引擎 | Godot 4.7 |
| 开发语言 | GDScript |

### 1.2 游戏简介

《Lost Land》是一款生存冒险游戏。玩家扮演一位神秘**，在孤岛上醒来。玩家需要在岛上采集资源、建造基地、探索未知区域，应对各种威胁，最终揭开这个世界的秘密。

### 1.3 开发背景与目标

**开发背景：**
- 玩家是编程新手，需要详细的系统设计和代码注释
- 已有Godot 4.7项目基础，包含物品系统、背包系统、资源采集系统的雏形
- 采用GDScript作为开发语言

**开发目标：**
- 第一阶段：完成Demo版本，包含核心生存循环、基础采集合成建造、1-2种敌人
- 第二阶段：EA版本，完善地图区域、敌人种类、科技系统、地下遗迹
- 第三阶段：完整版本，包含完整剧情、更多区域、NPC、成就系统

## 第二章：核心系统详细策划

### 2.1 电量系统

电量是机器人维持运转的核心资源，但不自动消耗。

#### 2.1.1 电量参数

| 参数 | 数值 |
|------|------|
| 最大电量 | 100 |
| 初始电量 | 100 |
| 电量消耗 | 仅通过特殊交互消耗，不自动减少 |

#### 2.1.2 电量回复

| 方式 | 效果 | 获取/触发条件 |
|------|------|--------------|
| 电池 | +10电量 | 击败敌人掉落、制作获得 |
| 能量核心 | +50电量 | 地下遗迹（未来） |
| 发电机 | 持续供电 | 建造发电机后，通过电线连接 |

#### 2.1.3 电量状态影响

| 电量范围 | 状态 | 影响 |
|---------|------|------|
| >10 | 正常 | 无负面影响 |
| ≤10 | 低电量 | 移动速度-30% |
| 0 | 濒危 | 每秒-1生命值 |

#### 2.1.4 生命值恢复

| 条件 | 效果 |
|------|------|
| 电量 > 80 | +5生命值/分钟 |

### 2.2 体温系统

体温反映机器人的热平衡状态，受环境影响而变化。

#### 2.2.1 体温参数

| 参数 | 数值 |
|------|------|
| 正常体温 | 10-40（无影响） |
| 过冷区间 | -10~10 |
| 过热区间 | 40~80 |
| 最大范围 | -100 ~ 100 |

#### 2.2.2 体温影响

| 体温区间 | 效果 |
|---------|------|
| 10-40（正常） | 无负面影响 |
| -10~10（过冷） | 每秒-0.5电量 |
| 40~80（过热） | 每秒-0.5电量 |
| <-10 或 >80 | 危险状态（待扩展） |

#### 2.2.3 各区域体温变化

| 区域 | 体温变化/分钟 | 说明 |
|------|-------------|------|
| 草原区 | 趋向30，变化10 | 自然回温 |
| 丛林区 | 趋向30，变化10 | 自然回温 |
| 沙地区 | 趋向30，变化10 | 自然回温 |
| 矿区 | 趋向30，变化10 | 自然回温 |
| 火山区 | +15 | 持续升温 |
| 雪地区 | -15 | 持续降温 |
| 熔炉附近 | +5 | 热源影响 |
| 地下遗迹 | 趋向30，变化5 | 恒温偏低 |

#### 3.1.3 防御机制

- 护甲提供防御点数
- 伤害计算：实际伤害 = max(攻击伤害 - 防御值, 1)
- 暴击伤害 = 攻击力 × 1.5 - 防御值
- 闪避机制：幸运值影响闪避率
