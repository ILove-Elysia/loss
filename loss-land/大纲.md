# 《Lost Land》游戏策划大纲 v0.3

---

## 第一章：项目立项概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《Lost Land》 |
| 游戏类型 | 3D俯视角生存建造游戏 |
| 核心玩法 | 采集、合成、建造、探索、充电生存 |
| 目标平台 | Steam PC |
| 开发阶段 | Demo优先，EA阶段补全 |

### 1.2 游戏简介

《Lost Land》是一款以机器人视角展开的生存建造游戏。玩家扮演一台失去记忆、外貌与人类无异的远古机器人，在四面环海的巨大孤岛上醒来。玩家需要在岛上采集资源、建造基地、探索未知区域，通过电池维持电量，应对极端体温环境，最终揭开这个世界的秘密。

### 1.3 开发背景与目标

**开发背景：**
- 玩家是编程新手，需要详细的系统设计和代码注释
- 已有Godot 4.7项目基础，包含物品系统、背包系统、资源采集系统的雏形
- 采用GDScript作为开发语言

**开发目标：**
- 第一阶段：完成Demo版本，包含核心生存循环、基础采集合成建造、1-2种敌人
- 第二阶段：EA版本，完善地图区域、敌人种类、魔法系统、地下遗迹
- 第三阶段：完整版本，包含完整剧情、更多区域

## 第二章：游戏整体设计

### 2.1 世界观

#### 2.1.1 背景故事

**"第八纪元" - 失落之岛的秘密**

远古文明"织星者"曾是这个世界的主宰。他们同时掌握了魔法与机械的力量，建造了悬浮的机械遗迹大陆。人类与机器人共同生活在织星者的庇护之下。

然而，一场名为"大静默"的灾变突然降临。魔法核心失控，机械大陆坠入地下，地表被魔法污染，岛屿被无尽海洋隔离。人类消失了，机器人陷入沉睡，等待重启的那一天。

**千年之后——**

你作为织星者的最后一台类人机器人，在沙滩上偶然启动。你的核心处理器受损，记忆几乎完全丢失。你只知道一件事：你的电量在不断流逝，机体在逐渐老化。

你必须在这个被遗忘的孤岛上生存下去，寻找电池能量来源，探索未知的区域，揭开"大静默"的真相。

## 第三章：核心系统详细策划

### 3.1 电量系统

电量是机器人维持运转的核心资源，但不自动消耗。

#### 3.1.1 电量参数

| 参数 | 数值 |
|------|------|
| 最大电量 | 100 |
| 初始电量 | 100 |
| 电量消耗 | 仅通过特殊交互消耗，不自动减少 |

#### 3.1.2 电量回复

| 方式 | 效果 | 获取/触发条件 |
|------|------|--------------|
| 电池 | +10电量 | 击败敌人掉落、制作获得 |
| 能量核心 | +50电量 | 地下遗迹（未来） |

#### 3.1.3 电量状态影响

| 电量范围 | 状态 | 影响 |
|---------|------|------|
| >10 | 正常 | 无负面影响 |
| ≤10 | 低电量 | 移动速度-30% |
| 0 | 濒危 | 每秒-1生命值 |

#### 3.1.4 生命值恢复

| 条件 | 效果 |
|------|------|
| 电量 > 80 | +5生命值/分钟 |

---

### 3.2 体温系统

体温反映机器人的热平衡状态，受环境影响而变化。

#### 3.2.1 体温参数

| 参数 | 数值 |
|------|------|
| 正常体温 | 10-40（无影响） |
| 过冷区间 | -10~10 |
| 过热区间 | 40~80 |
| 最大范围 | -100 ~ 100 |

#### 3.2.2 体温影响

| 体温区间 | 效果 |
|---------|------|
| 10-40（正常） | 无负面影响 |
| -10~10（过冷） | 每秒-0.5电量 |
| 40~80（过热） | 每秒-0.5电量 |
| <-10 或 >80 | 危险状态（待扩展） |

#### 3.2.3 各区域体温变化

| 区域 | 体温变化/分钟 | 说明 |
|------|-------------|------|
| 草原区 | 趋向30，变化10 | 自然回温 |
| 丛林区 | 趋向30，变化10 | 自然回温 |
| 沙地区 | 趋向30，变化10 | 自然回温 |
| 矿区 | 趋向30，变化10 | 自然回温 |
| 火山区 | +15 | 持续升温 |
| 雪地区 | -15 | 持续降温 |
| 熔炉附近 | +5 | 热源影响 |
| 地下遗迹 | 趋向30，变化5 | 恒温偏低 |

### 3.7 战斗系统

#### 3.7.1 战斗机制

**攻击方式：**
- 装备武器后，按F键进行近战攻击
- 攻击有冷却时间
- 攻击范围根据武器类型决定

**武器数据：**

| 武器 | 攻击力 | 攻击范围 | 攻击速度 |
|------|-------|---------|---------|
| 徒手 | 10 | 1米 | 0.8秒 |
| 木棍 | 15 | 1.5米 | 0.6秒 |
| 木剑 | 20 | 2米 | 0.5秒 |
| 石剑 | 28 | 2米 | 0.4秒 |

**防御机制：**
- 护甲提供防御点数
- 伤害计算：实际伤害 = 攻击伤害 - 防御值
- 最低伤害为1

#### 3.7.2 敌人设计

**史莱姆（近战型）：**

| 掉落物 | 史莱姆凝胶 x1 |
| 出没区域 | 丛林区、草原区边缘 |

## 第六章：版本迭代规划

### 6.1 Demo版本（当前目标）

**完成标准：**
- 玩家可以在草原区、丛林区、矿区自由移动
- 可以采集草、树、石头三种基础资源
- 可以合成工具、武器、护甲、建筑
- 可以建造工作台、熔炉、储物箱
- 可以装备武器和护甲
- 存在史莱姆和小型无人机两种敌人并可战斗
- 电量系统正常运行（电池供电）
- 体温系统正常运行
- 昼夜影响视野

### 6.2 EA阶段（后续目标）

- 完善地图区域（沙地区、火山区、雪地区）
- 完整地下遗迹
- 魔法系统
- 种植畜牧系统
- 更多敌人类型
