# 《Lost Land》游戏策划大纲

## 第一章：项目立项概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《Lost Land》/ 失落之岛 |
| 游戏类型 | 3D 俯视角生存建造游戏 |
| 核心玩法 | 采集 → 合成 → 建造 → 探索 → 战斗，由电量 / 体温 / 饱食度三条生存指标驱动 |
| 目标平台 | Steam PC（设计基准 1280×720，等比缩放适配任意分辨率） |
| 引擎 / 语言 | Godot 4.7 + GDScript |
| 当前阶段 | Demo —— 核心循环已可跑通，EA 阶段补内容 |

### 1.2 游戏简介

《Lost Land》是一款 3D 俯视角生存建造游戏。玩家可从**冒险家 / 魔女 / 机器人**三位角色中选一位开局，每人拥有一套**专属制作栏**与**专属系统**。三人都在**孤岛中央**醒来，岛上没有救援，玩家需要采集资源、合成工具、搭建营地、探索六大区域，在体温与饥饿的压力下活下去，弄清这座岛为何会被世界遗忘。

**与常规生存游戏的区别：** 三位角色的**基础数值完全相同**（生命 100 / 移速 ×1.0 / 攻击 ×1.0），差别**全部来自系统，不来自数字**。机器人多背一条"电量"线 —— 它是唯一开局就自带电量的角色，过冷过热时自身电量会额外流失，电量归零会掉血，但电量充沛时也能缓慢自愈；冒险家与魔女默认没有电量，过冷过热直接扣血，回血只能靠吃食物，日后可拾取「动力核心」获得一块外置电池。同一个岛，三种活法。

### 1.3 开发目标

| 阶段 | 目标 |
|------|------|
| **第一阶段 Demo** | 核心生存循环、采集 / 合成 / 建造、2 种敌人、昼夜、存档 |
| **第二阶段 EA** | 补齐 6 大区域内容、更多敌人、地下遗迹、魔法系统 |
| **第三阶段 完整版** | 完整剧情、多结局 |

## 第二章：游戏整体设计

### 2.1 世界观

#### 2.1.1 背景故事

一场突如其来的海难，把你抛上了这座四面环海的孤岛。

**你在孤岛正中央醒来**，浑身是伤、记忆残缺 —— 只记得自己是个四处漂泊的冒险家，却怎么也想不起是怎么来到这里的。身上一样东西都没剩下：没有工具、没有食物、没有同伴。

岛上有森林、矿区、火山与雪原，却没有救援、没有同类，只有游荡的怪物。你必须先活下来 —— 采集、合成、搭营地，再往岛的深处走，弄清这座岛为什么会被世界遗忘。

> 以上是**冒险家**线的开局叙事。魔女与机器人各有自己的来历，是否共用这段"孤岛醒来"的开场尚待确定（见 7.1）。

#### 2.1.2 世界分层

**表层（已实现）** —— 平面世界，无海拔高差，区域按同心圆环分布（见 4.2）。

```
                        ┌─────────────────────────────────┐
                        │        【失落之岛】表层          │
                        ├─────────────────────────────────┤
                        │  Tier 0 内圈 ─ 草原区（出生·中央）│
                        │  Tier 1 中圈 ─ 丛林 / 矿区 / 沙地 │
                        │  Tier 2 外圈 ─ 火山 / 雪地       │
                        │  岛缘 ─ 沙滩 ├ 外围 ─ 无尽海洋    │
                        └─────────────────────────────────┘
```

**深层（规划中）** —— 地下遗迹，共**三层**，入口在丛林区：一层是**变异的植物**，二层是**魔法与古老的雕像**，三层是**机械**（详见 4.6）。

### 2.2 角色系统

#### 2.2.1 角色阵容总览

**正式角色（3 个）**

| id | 显示名 | 一句话定位 | 核心特色 | 专属系统 | 专属制作栏 |
|----|--------|-----------|---------|---------|-----------|
| `adventurer` | **冒险家** | 靠双手与头脑在荒岛立足的生存者 | 能力待定 | 基础角色（默认无电量） | 求生制作 |
| `witch` | **魔女** | 用草药与符文改写规则的法术使用者 | 制药 / 魔法 | 制药魔法系统（待设计） | 炼药制作 |
| `robot` | **机器人** | 以电力驱动的机械生命，可自我改造 | 电量管理 / 机械改造 | 电量系统 | 机械制作 |

角色 id 会随存档记录，读档时据此还原角色、数值与外观。

**测试角色（3 个，开发期用于验证数值与换装，正式版移除）**

| 显示名 | 特性 | 移速倍率 | 最大生命 | 攻击倍率 |
|--------|------|---------|---------|---------|
| 青铠骑士 | 均衡 | ×1.0 | 100 | ×1.0 |
| 赤铁守卫 | 高血·高攻·慢 | ×0.9 | 130 | ×1.3 |
| 翠影斥候 | 高速·低血 | ×1.25 | 80 | ×0.85 |

#### 2.2.2 通用初始属性

除角色专属系统外，三个正式角色的基础数值完全一致：

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值 | 100 | 三角色一致 |
| 电量 | 100 / 100（仅机器人） | 不随时间消耗。电量属于**电池**而非人物：机器人有一块自身电量，动力核心自带一块外置电量（见 3.1） |
| 体温 | 30 | 身体的真实温度，正常区间 10 ~ 40；变化速度由温度值档位决定（见 3.2） |
| 温度值 | 500（正常档正中） | 环境给的热收支，范围 0 ~ 1000，由区域温度系数推动（见 3.2） |
| 饱食度 | 100 / 100 | 一个游戏日（480 秒）从全饱掉到空 |
| 攻击力 | 10（徒手） | 攻击范围 2.0 米，冷却 0.5 秒；三角色倍率均为 ×1.0 |
| 移动速度 | 5.0 米/秒 | 三角色倍率均为 ×1.0 |

#### 2.2.3 三个正式角色的对比

| 项目 | 冒险家 | 魔女 | 机器人 |
|------|--------|------|--------|
| 生命值 | 100 | 100 | 100 |
| 移速倍率 | ×1.0 | ×1.0 | ×1.0 |
| 攻击倍率 | ×1.0 | ×1.0 | ×1.0 |
| 电量系统 | ✗ 无（装上动力核心后获得一块**外置**电池） | ✗ 同上 | ✓ 有，100/100（**自身**电池） |
| 生存指标 | 体温 + 饱食度 | 体温 + 饱食度 | 体温 + 饱食度 + 电量 |
| 过冷 / 过热惩罚 | 扣血 | 扣血 | 扣血 ＋ 自身电量流失 |
| 回血方式 | 吃食物 | 吃食物 | 吃食物 ＋ 电量 > 80 时的自然回血 |
| 开局 | 默认开局角色 | 游戏内解锁（规划中） | 游戏内解锁（规划中） |

**设计意图：三个角色基础数值完全相同 —— 差异全部来自"系统"，不来自"数值"。**

- 好处是不必反复平衡强度：玩家比的是"想要哪种玩法"，不是"谁更强"；加新角色也只需设计系统，不用重算一遍数值表。
- 过冷 / 过热统一为"**扣血**（所有角色）＋ **自身电量流失**（仅机器人）"：火山 / 雪地对谁都有压力，机器人因此承受双份惩罚，这是它多一条补给线要付的代价。**核心那块电池不看人物体温**，它只看核心自己的温度值（见 3.1.4）。
- 回血出口分两层：**吃食物是所有角色通用的回血手段**；**自然回血是自身电量的专属福利**（仅机器人）。核心那块电池对人物本体零影响，既不扣血、不减速，也不给回血（见 3.1.1）。

#### 2.2.4 角色专属系统

**① 电量系统（机器人专属）**

| 项目 | 说明 |
|------|------|
| 谁会掉电 | 机器人（**自身电量**，按人物体温越界漏电）。冒险家 / 魔女默认没有自身电量，HUD 的 ⚡ 行显示灰色占位 `⚡ --`（见 6.1） |
| 受电量影响的效果 | 低电减速、归零掉血、高电自然回血 —— 只对**自身电量**（机器人）生效（见 3.1.1） |
| 解锁途径 | 拾取「动力核心」，装备到**核心槽** → 获得一块**外置**电池；核心还会按自己的温度值掉电（见 3.1.4） |
| 与角色本身的关系 | 核心只是在身上装了一台外挂设备，不改变角色本身（冒险家依然是冒险家），属于探索奖励 |

**② 魔女的制药魔法系统（待设计）**

已确认魔女拥有专属系统，深度暂未拍板。候选方向：

- 采集草药 / 魔力素材 → 炼药台 → 药剂（回血 / 抗寒 / 抗热 / 增益 / 解毒）
- 符文 / 法阵 → 短时改变地形或天气（与昼夜、温差系统联动）
- 与体温系统互补：药剂作为过冷 / 过热的第二种解法（第一种是熔炉取暖）

> 若做制药，需要新增草药 / 魔力素材两种资源，并为其设计分布、再生与生成规则 —— 这是该系统最大的一块隐性工作量。

**③ 冒险家的特殊能力（待设计）**

候选方向：

- 野外求生：生火、搭简易庇护所、设陷阱（可不依赖工作台）
- 采集大师：资源掉落量 / 每一下的采集工作量加成
- 用"体力 / 精神"替代电量？（注意与机器人的电量**不要重复**：电量是长期续航，体力应作短期爆发，否则两个角色玩起来一样）

> 在能力确定前，冒险家作为规则的基准角色（无额外负担）可直接开局试玩。

**④ 专属物品的使用权限**

专属物品**只限制"使用"，拾取与携带一律放开** —— 专属物品可能出现在宝箱里被别的角色捡到，捡到不能用已经够让人窝火，捡都不让捡更糟。

| 策略 | 含义 |
|------|------|
| 通用 | 谁都能用 |
| 归属加成 | 谁都能用，归属角色使用时效果加倍（如 ×1.5） |
| 专属锁定 | 只有归属角色能用 |

当前 6 件专属物品：

| 物品 | 归属 | 策略 | 说明 |
|------|------|------|------|
| 草药绷带 | 冒险家 | 通用 | 谁都能用来回血 |
| 干粮 | 冒险家 | 通用 | 同上 |
| 治疗药剂 | 魔女 | 通用 | 同上 |
| 活力药剂 | 魔女 | 通用 | 同上 |
| 高容量电芯 | 机器人 | 专属锁定 | 只有机器人能用（+60 电量），别人用了没有意义 |
| 维修包 | 机器人 | 归属加成 ×1.5 | 谁都能用来回血，机器人使用效果 ×1.5 |

> 完全锁死会让玩家"捡到一件好东西却只能扔掉"，体验很差；完全不差异又会让"专属"失去意义 —— 折中做法是**基础功能通用、加成专属**。
> 专属**装备**的权限（武器 / 护甲 / 工具 / 核心槽）尚未纳入同一套规则，规划中。

**⑤ 角色解锁策略**

| 阶段 | 规则 |
|------|------|
| 正式目标 | 冒险家为开局角色；魔女 / 机器人作为后续奖励，通过游戏内途径解锁（与遗迹探索天然结合） |
| 开发 / Demo 期 | 三个角色全部开放、任选开局，便于测试与试玩 |

> 两者是"目标态"与"当前态"的关系，正式发布时收紧为"冒险家开局 + 解锁制"。

#### 2.2.5 角色专属制作栏

每个角色除通用分类（材料 / 工具 / 武器 / 护甲 / 建筑）外，还拥有一栏**专属标签**，只在对应角色的合成界面出现。

| 专属栏 | 归属 | 配方 | 说明 |
|--------|------|------|------|
| 求生 | 冒险家 | 草药绷带（草 ×5 + 木棍 ×1，回 25 生命）、干粮（浆果 ×3 + 草 ×2，+40 饱食 +15 生命） | 冒险家没有自然回血，靠自制补给续命 |
| 炼药 | 魔女 | 治疗药剂（浆果 ×5 + 史莱姆凝胶 ×2，回 50 生命）、活力药剂（浆果 ×3 + 史莱姆凝胶 ×3 + 草 ×2，+60 饱食 +20 生命） | 深度待定（见 2.2.4-②） |
| 机械 | 机器人 | 高容量电芯（电池 ×2 + 铁锭 ×1，+60 电量）、维修包（铁锭 ×2 + 木棍 ×2，回 40 生命） | 唯一有电量的角色，专属栏全是能量与自检维修 |

> **专属制作站（规划中）**：炼药台 / 装配台 —— 谁都能放置，但只有对应角色能出配方。当前专属配方无需制作站。

## 第三章：核心系统详细策划

### 3.1 电量系统

**电量不属于人物，而属于一块电池。** 游戏里存在两种电池，各自按自己的规则结算：

- **自身电量** —— 机器人的机械身体自带，100/100，不可拆卸，不随时间消耗。它是机器人的生命线。
- **核心电量** —— 装在**动力核心**这件物品上的电池。核心是会流转的独立单位，电量连同它自己的温度值一起跟着这件物品走。

冒险家 / 魔女没有自身电量 —— HUD 的 ⚡ 行是灰色占位，下列"影响人物本体"的效果（低电减速、归零掉血、高电回血）一律不生效。他们装上一枚动力核心后，才拥有一块（外置的）电池。

#### 3.1.1 两种电量语义（自身 / 核心）

**分界线是"电量能否影响人物本体"。** 核心那块电池不是"机器人的电量换个皮"，它对人物本体**零影响**。

| 效果 | 自身电量（仅机器人） | 核心电量 |
|------|---------------------|----------|
| 电量归零掉血（-1 HP/秒） | ✅ | ❌ |
| 低电（≤10）减速 ×0.7 | ✅ | ❌ |
| 电量 > 80 且吃饱缓慢回血（+5 HP/分） | ✅ | ❌ |
| 掉电渠道 | **人物体温**越界（≤10 / ≥40）时每秒 -0.5（见 3.2.2） | **核心自己的温度值**越界（< 350 / > 650）时每秒 -0.5（见 3.1.4） |
| 能否关闭 | ❌（不可拆除） | ✅（可拆；**拆下后电量留在核心里，不会清零**） |
| 回血出口 | 吃食物 ＋ 自然回血 | 只有吃食物 |

- 两条漏电渠道**互不相干**：人物的体温越界只扣血（所有角色一视同仁），核心的电只认**核心自己的温度值**。
- 机器人装上核心就有两块电池，**各自按自己的规则结算**，互不干扰；使用电池时两块各充一次。
- 核心电量保留的意义有两个：**耗电交互可用**（消耗电量的配方与设备），以及**解锁「核心」制作栏**（见 3.6.7）—— 后者才是玩家愿意背着它的理由。
- 判断某个角色当前有没有电量，要看**运行时状态**（核心可装可拆），不能只看角色的开局设定。

#### 3.1.2 参数

| 参数 | 自身电量（机器人） | 核心电量 |
|------|-------------------|----------|
| 最大 / 初始 | 100 / 100 | 100 / 100（新核心出厂满电） |
| 自动消耗 | 无 | 无 |
| 特殊消耗 | 人物体温越界时每秒 -0.5（见 3.2.2） | 核心温度值越界时每秒 -0.5（见 3.1.4） |
| 补充 | 电池 +10（可合成）；大型电池 +50（规划中） | 同左 —— 使用电池时两块各充一次 |
| 复活 | **回到上限一半**（自身电量 / 饱食度各半；HP 半血） | **清零**（携带核心复活后电量归 0；死亡不掉电，复活抹充能） |

> **「动力核心」与「电池」是两回事**：核心用来**解锁电量**，电池用来**补充电量**。

#### 3.1.3 电量状态影响（仅自身电量 / 机器人）

| 电量范围 | 状态 | 影响 |
|---------|------|------|
| > 80 | 充沛 | 生命值自然恢复 **+5 HP/分钟**（需同时满足"不饿"，见 3.3.2） |
| 11 ~ 80 | 正常 | 无 |
| ≤ 10 | 低电量 | 移动速度 **×0.7** |
| = 0 | 濒危 | 每秒 **-1 生命值** |

> 自然回血的完整条件是**电量 > 80 且 饱食度 > 20 且未满血**，按累积器结算整数 HP。核心电量既不回血也不掉血，回血只能靠吃食物（见 3.3.2）。

#### 3.1.4 动力核心

动力核心是一件**探索途中的拾取物** —— 来历不明的遗物，装到谁身上，谁就有了电量。

| 项目 | 内容 |
|------|------|
| 类型 | 可入包物品，装备到**核心槽**（不是消耗品，不会被"用掉"） |
| 获取 | 击败机械沙虫后掉落（见 5.1.3）。正式投放点尚未实装；开发期为便于验证，出生点旁的储物箱里会提供一个 |
| 作用 | ① 提供一块 100/100 的**外置**电池（语义见 3.1.1：不掉血 / 不减速 / 不回血）；② 合成界面多出一个**「核心」栏目**（见 3.6.7） |
| **核心自带两个数** | **电量**与**温度值**。两者都跟着这件物品走 —— 装在身上、放在背包、丢在地上都照样结算。把一枚用了一半的核心拆下来再装回去，它**还是半电** |
| 核心的温度值 | 0 ~ 1000，出厂 500（正常档正中）。按**它所在位置**的环境温度系数推进（与人物温度值同一套规则，见 3.2）；低到 350 以下**过冷**、高过 650 **过热**，此时每秒消耗 **0.5** 电量 |
| 丢在地上 | 地上的核心是一个**独立单位**：丢在雪地里它会自己冻到掉电、放在火山旁会自己烤到掉电，与玩家跑到哪去无关 |
| 对机器人 | 机器人开局自带自身电量，核心就是它的第二块电池：两块各自结算，互不干扰 |
| 可否拆除 | 可以，装拆双向 —— 解锁是一次主动的风险交易，而非单向陷阱。**拆下后电量留在核心里**，重新装上不会回满 |
| 装入 / 拆除入口 | **装备面板的「核心」槽**：把核心放进槽位即装入，点击槽位即拆除 |

> **设计动机：** 电量作为**探索的回报**出现，与"往岛的深处走"同向；三个人物的差异能一直保留到玩家真正做出选择为止；核心的来历则成为悬念，不必在开场硬解释。
>
> **它同时是一个"制作栏开关"。** 核心槽是全局唯一"装备决定界面"的出口：谁能塞进带开关属性的核心，谁的合成界面就多一栏。日后的**机械核心**（见 3.6.7）走的是同一套机制 —— 两件核心共用"核心槽 + 核心栏目"这一对接口，加第三件也不用改规则。

### 3.2 温度系统

角色身上有**两个不同的温度属性**：

- **温度值** —— 环境累积在身上的"热收支"，范围 0 ~ 1000，**本身不造成任何伤害**；
- **体温** —— 身体的真实温度，正常区间 10 ~ 40，**越界才会真的伤人**。

一句话概括两者的关系：**温度值决定体温往哪个方向走、走多快**。玩家站在哪块地上，决定温度值怎么变；温度值落在哪一档，决定体温怎么变。

> **这套温度场是共用的**：动力核心也带一个自己的**温度值**，按同一套区域系数推进，只不过它只影响自己那块电池（见 3.1.4）。

#### 3.2.1 参数

**温度值**

| 参数 | 数值 |
|------|------|
| 范围 | 0 ~ 1000（开局 500，即正常档正中） |
| 影响因素 | 所处区域的**温度系数**（见 3.2.3） |

温度值随时间的变化就是区域内温度系数的累加：

> **玩家温度值 = 原有温度值 + 温度系数 × 时间**

在中性区（温度系数 = 0），温度值改走**回中**规则：以 **±10/秒** 朝 500 靠拢，高于 500 就降、低于 500 就升，**补到 500 停手**。

**温度值档位 → 体温变化速度**

| 温度值区间 | 档位 | 体温变化速度 |
|-----------|------|-------------|
| 0 ~ 100 | 非常冷 | **−2 °/秒** |
| 100 ~ 350 | 冷 | **−1 °/秒** |
| 350 ~ 650 | 正常 | **0** |
| 650 ~ 900 | 热 | **+1 °/秒** |
| 900 ~ 1000 | 非常热 | **+2 °/秒** |

> **体温 = 原有体温 + 体温变化速度 × 时间**

温度值越低，体温掉得越快；温度值越高，体温升得越快 —— 一旦离开"正常"档，失温或中暑会自己加速，拖得越久越难回头。

**体温**

| 参数 | 数值 |
|------|------|
| 正常区间 | 10 ~ 40（无影响） |
| 绝对值范围 | −100 ~ 100 |
| 自然回温 | 温度系数为 0 的地方（中性区）趋向 30，**10/分钟** |

**档位速度原样生效，环境推力不插手。** 体温只认温度值所在的档位，不会因为"环境正在加热"就网开一面。于是带着一身寒气冲进火山的人，只要温度值还在冷档，体温就会**继续掉**，要等温度值被推过 650 才转为回升 —— 过冷的人进温暖环境不会立刻变暖；反过来从火山冲进雪地，也会先把身上的热气散完再开始变冷。

#### 3.2.2 体温影响

| 体温区间 | 所有角色 | 有自身电量时额外（仅机器人） |
|---------|---------|-------------|
| 10 ~ 40（正常） | 无 | 无 |
| ≤ 10（过冷） | 每秒 **-0.5 生命值** | 每秒 **-0.5 自身电量** |
| ≥ 40（过热） | 每秒 **-0.5 生命值** | 每秒 **-0.5 自身电量** |

- 温度惩罚**先扣血**（对所有角色生效），**再额外漏自身电量**（仅机器人）。火山 / 雪地对谁都有压力，不会因为没有电量就白送难度；机器人则双份承担。
- **核心那块电池不走这条渠道** —— 它只看核心自己的温度值（见 3.1.4）。所以"人物体温越界"与"核心温度值越界"是两条互不相干的漏电渠道。
- 选择"扣血"而不是"减速"，是因为减速只是拖慢节奏、不会真的逼玩家撤退；扣血会直接把"带够补给 / 早点回营地"变成硬需求 —— 与之配套的回血出口就是吃食物（见 3.3.2）。

#### 3.2.3 各区域温度系数

温度系数是一个**带正负号的常数**（单位：温度值/秒），每个区域各不相同。正数代表这块地在给角色加热，负数代表在降温，**0 代表中性区** —— 它不主动加热也不主动降温，而是把温度值**往常温 500 拉**（见下方"回中"规则）。

| 区域 | 温度系数 | 说明 |
|------|---------|------|
| 火山区 | **+6.0 / 秒** | 全岛**唯一的热源区**，十几秒就能把温度值推离正常档，久留必被烤熟 |
| 草原区 / 丛林区 / 矿区 / 沙地区 / 沙滩 | **0** | 中性区 —— 温度值以 **±10/秒** 回中，是玩家的"家" |
| 雪地区 | **−6.0 / 秒** | 全岛**唯一的冷源区**，与火山对称 |
| 海洋 | **0** | 中性 —— 落水本身就会淹死，不再叠加温度惩罚 |
| 地下遗迹 | — | Demo 无地下区域（规划中） |

**中性区有两条收尾规则**：温度值以 **±10/秒** 朝 500 回中（把从火山 / 雪地带回来的余温与余寒慢慢抹平），体温则由身体自己回温到 30（10/分钟）。所以所有中性区都是安全的整备区 —— 一身寒气或一身燥热都会在这里散掉，这也是"中性区"存在的意义，否则玩家一旦在雪地失温就再也回不了头。

**熔炉是移动的热源**

| 环境 | 效果 |
|------|------|
| 熔炉附近（5 米内） | 温度值以 **+20/秒** 持续上升，**不封顶在常温**，最高到 1000 |
| 补温途中 | 温度值还在冷档，体温照旧按档位继续掉（−1°/秒），烤火不是立竿见影 |
| 越过 650（热档）之后 | 体温转为回升 —— **在火边待久了会过热**，得自己挪开 |

火炉只管加热，不负责"退回常温"：它在雪地里能把人从冻僵里拉回来（+20/秒 压过地形的 −6/秒），但一直烤下去也会把人烤到过热 —— 和饥荒的火堆一样，火边是"待一会儿"的地方，不是"待着不动"的地方。


### 3.3 饱食度系统

角色和常人一样需要进食补充体力，所以会饿：饿到阈值会减速、掉血，而**吃食物是回血的主要手段** —— 于是吃饭这件事变得和打架一样重要。

#### 3.3.1 参数

| 参数 | 数值 |
|------|------|
| 最大 / 初始饱食度 | 100 / 100 |
| 消耗速率 | **100 / 480 每秒** —— 一个游戏日（480 秒）从全饱掉到空 |
| 饥饿阈值 | ≤ 20 |
| 温饱阈值 | ≥ 80 |
| 饥饿惩罚 | 移动速度 **×0.9**，且**停止自然回血** |
| 归零惩罚 | 每秒 **-0.5 生命值**（比电量归零的 -1.0 温和，留出找食物的时间） |

#### 3.3.2 回补方式（饱食度 / 生命值）

| 方式 | 效果 | 说明 |
|------|------|------|
| 浆果 | **+25 饱食度** ＋ **+10 生命值** | 空手可采，浆果丛 240 秒再生 |

- **吃食物 = 补饱食度 且 回血**，两者一起结算，是**所有角色通用**的回血手段。
- **只有机器人**另有"电量 > 80 且吃饱"的缓慢自然回血（+5 HP/分钟）作为额外福利；核心电量不回血（见 3.1.1）。
- **防滥用门槛：饱食度已满时整次进食作废**（含回血），判断在结算前 —— 否则"满着肚子啃浆果回血"会抹平战斗与环境的风险。
- 一条食物可以同时给多个属性加成（例如浆果既补饱食度也回血）。

#### 3.3.3 移速惩罚合并规则

低电量与饥饿**不相乘**，取更狠的那个 —— 相乘会让残血玩家几乎走不动路。

| 状态 | 移速乘数 |
|------|---------|
| 正常 | ×1.0 |
| 仅饥饿 | ×0.9 |
| 仅低电量（自身电量） | ×0.7 |
| 又饿又没电（自身电量） | ×0.7（取小值，不是 0.63） |

> 核心电量不参与低电减速（见 3.1.1）。

### 3.4 生命、死亡与复活

#### 3.4.1 伤害计算

```
实际伤害 = max(1, 敌方攻击力 - 玩家防御力)
```

护甲可以减免伤害，但**至少掉 1 点**，避免堆防御后完全无敌。

#### 3.4.2 死亡条件

| 死因 | 判定 |
|------|------|
| 生命值归零 | 被敌人打死 / 电量归零持续掉血 / 饥饿归零持续掉血 / 过冷过热持续扣血 |
| 落水 | 走进海洋 —— 海水**没有碰撞体**，踩上去就是自由落体，坠到一定深度判定溺亡 |

#### 3.4.3 死亡 → 复活流程

```
死亡 → 画面转灰暗 + 屏幕底部中央 5 秒倒计时
     → 倒计时结束 / 点击"复活"按钮 → 原地**半血**复活（所有属性回到上限一半，体征重置、画面恢复正常、镜头直接对准角色）
```

- 死亡流程不会重复触发倒计时。
- 敌人目标判定统一为"玩家是否活着"：玩家一死，史莱姆与无人机**立刻放弃追击 / 停火**，复活后自动重新锁定。
- 复活时**所有属性回到上限一半**：生命（HP 半血）、饱食度半、机器人的**自身电量**半（机械身体重启，但仍残血）；体温与温度值回到常温档（非减半，减半会落过热区）。**携带的核心复活后电量清零** —— 核心是独立单位，死亡期间温度冻结不掉电，但复活作为惩罚把充能抹掉，得靠玩家拿电池充。
- 镜头在复活瞬间直接落到角色身上，不播放移动过程。

**画面滤镜**

| 滤镜 | 触发 |
|------|------|
| 死亡 | 画面转灰暗（死亡期间常驻） |
| 低血量 | 血量过低时常驻 |
| 受击 | 受击瞬间的短促脉冲 |
| 过热 / 过冷 | 预留（规划中） |

> 滤镜与昼夜系统共用同一个环境效果，染色 / 暗角类效果尚未启用。

| 煤矿 | 煤矿 | **镐** | 每下 1 秒 × 6 下（石镐）/ 4 下（铁镐） | 1~2 煤矿 | ✗ | 140 |

#### 3.5.2 采集方式

- **全鼠标操作**：左键点击资源 → 角色自动走近 → 进入 **3 米**范围后停下采集。
- 工具不足时只闪提示，不进入采集（不会白跑一趟）。
- 交互距离与建造放置距离统一为 **3.0 米**。

**工作量：树和大石头要"砍几下"才倒**

草、木棍、浆果、小石块这类一碰就到手（挥一下就掉）；
**树、大石头、铁矿、煤矿**则各有一份 **24 点工作量**（相当于它们自己的一条血条）：
每挥一次工具，扣掉这件工具"每次能完成的工作量"，扣完才倒下 / 碎裂；**每下耗时 1 秒**。
中途走开、被打断都不会清零——砍到一半的树，回来接着砍剩下的那几点。

**好工具是"每下做得多"，不是"挥得快"：**

| 工具 | 每次工作量 | 砍倒一棵树 | 挖穿一块大石头 / 铁矿 / 煤矿 |
|------|-----------|-----------|---------------------------|
| 石斧 / 石镐 | 4 | 6 下 | 6 下 |
| 铁斧 / 铁镐 | 6 | 4 下 | 4 下 |

**认工具不认人**：树只认"斧"这一类工具，大石头 / 铁矿 / 煤矿只认"镐"——
手里拿错东西（或空手）就采不动，只闪一行提示。

**树的两点特殊表现：**

- **树干挡路**：树是实体障碍，树干占一圈半径约 0.45 米、高约 2 米的碰撞，角色和敌人走到近前会被挡住绕行；树冠不挡路，可以从树下穿过去。
- **砍伐反馈**：每挥一下，树就晃一遍（人物同步做出挥砍动作），砍完（木材进背包的那一刻）整棵立刻从画面上消失，不留树桩。

#### 3.5.3 区域资源分布

| 区域 | 可产资源 |
|------|---------|
| 草原区 | 木棍 · 草 · 树 · 浆果 · 小石块 |
| 丛林区 | 木棍 · 草 · 树 · 浆果 · 小石块 |
| 矿区 | 小石块 · **石头** · 铁矿 |
| 火山区 | **煤矿** · 铁矿 |
| 雪地区 | 木棍 · 小石块 |
| 沙地区 | 木棍 · 小石块 |
| 沙滩 | 木棍 · 小石块 |
| **废墟区**（浮空岛坠落后） | **磁石** |

**设计后果（有意为之）：**

- **石头只在矿区** → 想升级到石制 / 铁制工具，必须冒险进入矿区。
- **煤矿只在火山区** → 冶炼铁锭需要远征。
- **磁石只在废墟区** → 它是全岛最后一种矿，必须先走完巨鸟线、让浮空岛坠落后才拿得到。
- 树 / 草 / 浆果集中在草原与丛林，构成"植被带"。

#### 3.5.4 生成规则

按区域地形**精确采样**：先给每种地形的瓦片建立索引，再按瓦片数加权随机取点，配合障碍射线与最小间距检查 —— 保证分布在小区域里的稀有资源（如火山煤）也能足量生成。

#### 3.6.7 核心制作栏

**装备了带"制作栏开关"属性的核心**（动力核心见 3.1.4、机械核心见 5.1.3），合成界面就会多出一个**「核心」栏目**；把核心拆下来，这一栏随之消失。

| 产物 | 材料 | 说明 |
|------|------|------|
| 保暖内衣 | 草 ×8 ＋ 木棍 ×2 | 护甲，防御 +2。**占位配方**，保暖效果待补充 |

> **核心栏与角色专属栏是两套独立的东西**：专属栏看"你是谁"，核心栏看"你装备了什么" —— 无论使用哪个角色，只要核心槽里装着核心就看得见这一栏；同一个角色拆掉核心，这一栏也就没了。
>
> 这一栏是核心的**长期价值所在**：核心本身只提供电量，真正让玩家愿意背着它的，是它解锁的这批配方。内容会随着日后的电力设备一起补上（规划中）。

#### 3.6.8 主线配方（规划中）

| 产物 | 材料 | 制作站 | 说明 |
|------|------|--------|------|
| **降落伞** | **羽毛** ＋ 其他材料（配比规划中） | 规划中 | 主线道具，**带耐久度**：每次使用消耗 1 点，耐久归零即损坏消失 |

> **耐久只会消耗在"回地面"这件事上** —— 使用降落伞的效果就是离开浮空岛回到矿区，所以**不存在"人在岛上、伞却没耐久"的情况**；耐久真正会耗尽的地方是**地面**，后果是暂时无法再上岛，需要用羽毛重做一顶。
>
> **羽毛的再生来源：** 羽毛由巨鸟掉落（见 5.2.2）；**好感度满之后，鸟巢还会定期留下羽毛和其他奖励**（见 5.2.5）。因为降落伞是**消耗品**，羽毛必须有稳定的补充渠道 —— 否则用一次就少一次，巨鸟线会被自己的消耗卡死。

#### 3.6.9 配方系统机制

- **制作站门槛**：部分配方需要工作台 / 熔炉；缺站时材料齐了也做不出来，界面会提示"需要熔炉"。
- **缺口预览**：材料不足时逐项显示"需要几个 / 现有几个"。
- **失败回滚**：合成失败会自动返还已扣材料，不会凭空吞材料。

#### 3.6.10 开局破局链（核心循环）

```
空手捡小石块 + 草
   → 合成【粗制石斧】（石头×3 + 草×3）
   → 砍树得木材
   → 合成【木镐】（木材×3 + 石头×3）—— 石头来自沿途捡的小石块
   → 进矿区挖大石头（须镐）→ 得石头
   → 回草原建【工作台】（木材×10）→ 解锁石斧 / 石镐 / 石剑 / 木甲
   → 攒石头 ×20 建【熔炉】
   → 进火山区挖煤 → 熔炉炼铁锭 → 铁制装备
```

- 每个存档都带地形自检信息（哈希）与格式版本号：地形数据损坏、或存档来自更新版本时，会明确提示而不是静默出错。老存档（无地形段）仍可读取，按种子重算地形。

## 第五章：主线与 Boss 战（规划中）

> 两条区域主线：沙地区的**沙虫**与丛林区的**巨鸟**。两条线的节奏完全一样 —— **遭遇 → 打不过可以撤 → 击退 → 打开一片新区域**；区别只在收尾：沙虫线把玩家送进地下的实验室，巨鸟线把玩家送上巨树。

### 5.1 沙地区主线：沙虫

#### 5.1.1 沙虫巢穴

| 项目 | 内容 |
|------|------|
| 位置 | 沙地区 |
| 外观 | 沙地上的一块**四边形凹坑，被沙子覆盖**（贴图规划中） |
| 状态 | **完好** / **坍塌** |

#### 5.1.2 第一阶段：地表战

- 玩家**靠近巢穴并停留一段时间**后，一只**巨大的沙虫**从巢穴中钻出，主动攻击玩家。
- 玩家若及时远离、让沙虫**丢失目标**，它会**回到巢穴并补满血量** —— 靠反复消耗磨死它是行不通的，必须一次打完。
- 沙虫**即将死亡**时：
  - 掉落**战利品**（内容规划中）
  - **保留最后 1 点生命、进入无敌状态**，逃回巢穴
  - **巢穴坍塌**

#### 5.1.3 第二阶段：坍塌巢穴与实验室

- **巢穴完好时进不去**，只有坍塌后才能进入 —— 这本身就是一道进度门。
- 穿过巢穴，玩家来到一所**神秘的实验室**（房间内容规划中）。
- 实验室的终点，是那条**没被杀死的沙虫** —— 它已被改造成**机械沙虫**。
- 机械沙虫同样可以脱离：玩家**逃出房间**即可让它丢失目标，但它会**回满血**。
- 击败机械沙虫，获得**机械核心**（见 3.6.7）。

### 5.2 丛林区主线：巨鸟

#### 5.2.1 巨树与盘旋的巨鸟

| 项目 | 内容 |
|------|------|
| 巨树 | 丛林区内一棵**巨大的树**（位置与贴图规划中） |
| 巨鸟 | 绕着巨树**盘旋**，尚未落地（名称规划中） |
| 地面提示 | 巨鸟在**地面投下影子**，提示"它就在你头顶" |

#### 5.2.2 第一阶段：地面战

- 玩家**试图靠近巨树**时，巨鸟会**降落**并与玩家战斗。
- 玩家远离、让巨鸟**丢失目标**后，它会飞回树上并**回满血**。
- 巨鸟**即将落败**时：
  - **吐出一颗特殊种子**
  - 掉落**羽毛** —— **降落伞的制作材料**（见 3.6.8）
  - **保留最后 1 点生命、进入无敌状态**，**飞回树上**

#### 5.2.3 第二阶段：种子与巨树之上

- 把**特殊种子种在巨树旁**，**几天之后**（按游戏内天数计）种子长出**藤蔓**，环绕着巨树。
- 玩家**攀爬藤蔓**登上巨树，抵达**巨树之上**。

#### 5.2.4 树顶：鸟巢与鸟蛋

- 巨树之上有巨鸟的**巢**，巢中有**鸟蛋**（数量与用途规划中）。
- 此时的巨鸟**不再是敌人** —— 它守在巢边，转为一只**中立生物**：不再主动攻击，但会守护鸟巢。
- 玩家靠近鸟巢触发的是**互动**而不是战斗 —— 这是整条巨鸟线的转折点：**打赢它只是开始，取得它的信任才是目的。**

#### 5.2.5 巨鸟好感度

好感度是一条**独立于战斗的成长线**，分**若干个阶段**（阶段数与数值规划中）。玩家通过以下途径提升：

| 途径 | 说明 |
|------|------|
| **喂食** | 把食物交给巨鸟（具体种类与效果规划中） |
| **赠送道具** | 献上它愿意接受的物品（具体物品规划中） |
| **修缮鸟巢** | 用材料修补、加固鸟巢（所需材料与次数规划中） |

好感度提升会同时改变两件事：

| 变化对象 | 表现 |
|---------|------|
| **巨鸟的行为** | 从敌对、警戒，逐渐变为容忍、亲近，最终愿意载人飞行 |
| **鸟巢的外观** | 从破损、简陋，逐步被修缮得更完整（各阶段的造型规划中） |

> 行为与外观是**同一条好感度的两面**：玩家每做一次修缮，都能立刻在巢的样子上看到反馈，而不只是数字在涨。

**好感度满之后，鸟巢会定期留下谢礼** —— 玩家可以随时回来取：

| 项目 | 说明 |
|------|------|
| 刷新内容 | **羽毛** ＋ **其他奖励**（具体种类规划中） |
| 刷新周期 | 规划中（按游戏内天数计） |
| 领取方式 | 回到鸟巢拾取（未领取的会保留，规划中） |

> 这条规则让**羽毛成为可再生资源**：降落伞是消耗品（见 3.6.8），羽毛必须能持续补充，巨鸟线才不会被自己的消耗卡死。同时它也让"养鸟"这件事在拿到坐骑之后**仍然有回报**，而不是一次性交易。

#### 5.2.6 第三阶段：骑乘巨鸟

- **好感度满**之后，玩家**携带降落伞**与巨鸟互动，即可**骑乘巨鸟**。
- 巨鸟载着玩家飞离巨树，前往空中的**浮空岛**（见 5.3）。
- 降落伞是**消耗品**，**每次使用消耗 1 点耐久，耐久归零即损坏**；想再飞就得用**羽毛**重做一顶（见 3.6.8）。
- 它既是骑乘的**必要前提**，也是**离岛的唯一手段**。不过使用即离岛，所以**不会有人在岛上用完耐久** —— 耐久只会在地面上慢慢见底，届时只是暂时上不了岛，重做一顶即可。

### 5.3 浮空岛：巨剑守护者

#### 5.3.1 矿区中心的阴影

浮空岛悬在**矿区中心的正上方**。玩家在地面上**看不见它**，只能看到它投下的一片巨大阴影。

| 项目 | 内容 |
|------|------|
| 阴影位置 | **矿区中心** |
| 玩家视角 | 只看得见阴影，**无从得知阴影从何而来** —— 这是留给玩家的悬念 |
| 阴影区的限制 | 附近**没有采集物**（矿石、石头、石块等一律不生成），也**无法放置建筑** |
| 限制的意义 | 为浮空岛日后**坠落**预留出一片空地 —— 岛上第一眼看到的"空旷"，其实是伏笔 |

#### 5.3.2 浮空岛的外观

| 项目 | 内容 |
|------|------|
| 整体形状 | 一个**球体被切掉上端约五分之一** |
| 上部平台 | 切面是与地面平行的**圆形**，玩家在这里活动 |
| 平台中心 | 放置着一枚**核心** |
| 区域性质 | **单纯的战斗区域** —— 不产出资源、不能建造、**可以存档** |

> 可以存档，也就意味着玩家可能**在岛上读档**。因此降落伞不只是脱战手段，还是**随时离开浮空岛的方式** —— 只要还带着它，从平台边缘跳下就能回到矿区（代价是 1 点耐久）。

#### 5.3.3 Boss 战：巨剑守护者

- 玩家由巨鸟送到上部平台，与**巨剑守护者**（暂定名）展开战斗。
- 战败或想撤退时，玩家可以**使用降落伞从平台边缘跳下**脱离战斗 —— 这也是**随时离开浮空岛的方式**，不只在战斗中可用。
- 跳下后**随机传送到矿区某处**。

#### 5.3.4 取走核心与浮空岛坠落

- 战胜巨剑守护者，获得**战利品**（内容规划中）。
- 玩家可以**从平台中心取走核心**（核心用途规划中）。
- **取走核心的一刻，浮空岛失去支撑，坠向矿区** —— 玩家同样视为使用降落伞，被传送到矿区某处。
- 无论打赢后取核心，还是中途逃跑，玩家最终都会回到地面；区别只在于**浮空岛有没有掉下来**。

#### 5.3.5 新区域：废墟

浮空岛坠落后，在矿区中心砸出一片**废墟区**：

| 项目 | 内容 |
|------|------|
| 整体形态 | 球体像**核桃一样裂开**：**两侧是两瓣"壳"**，**中间是废墟区域** |
| 中央废墟 | 可探索的新区域（内容规划中） |
| 新资源 | **磁石** —— 只生长在**两侧壳**上，可供开采（用途规划中） |

> 这片区域正是 5.3.1 里那块"没有采集物、不能建造"的空地所换来的 —— **玩家第一次路过矿区时看到的那片反常的空白，最终会变成全岛最独特的矿场。**

### 5.4 主线设计要点

| 要点 | 说明 |
|------|------|
| **Boss 打不死** | 两条主线的 Boss 在濒死时都不会死，而是保留最后 1 点生命逃走 —— "打赢"不等于"打死"，而是让它退走、打开下一层 |
| **打不过可以撤** | 每个 Boss 都允许玩家脱离战斗，逃开即回满血；但**进度不会白送** |
| **先打后开** | 巢穴要**先击退沙虫**才会坍塌、才进得去；藤蔓要**先击退巨鸟**拿到种子才长得出来 —— 玩家必须先赢一场，才能打开新区域 |
| **Boss 可以化敌为友** | 巨鸟线在击败之后转向**好感度**：从敌人变成坐骑。这是两条主线最大的不同 —— 沙虫线是一条越走越深的战斗线，巨鸟线是一条从对抗到结盟的关系线 |
| **主线会改造地图** | 巢穴坍塌、藤蔓生长、浮空岛坠落成废墟 —— 主线推进会**永久改变地表**，玩家回头时能看见自己造成的痕迹 |
| **先埋伏笔，后给答案** | 矿区中心那片"没有资源、不能建造"的阴影区，在玩家还不知道浮空岛存在时就已经存在；等浮空岛真的砸下来，伏笔才兑现 |
| **两条线各自独立** | 沙虫线在沙地、巨鸟线在丛林，互不依赖，玩家可自行决定先后（规划中） |
| **Boss 数值** | 血量、伤害、攻击方式与阶段技能均**规划中** |
