# 《Lost Land》游戏策划大纲

## 第一章：项目立项概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《Lost Land》/ 失落之岛 |
| 游戏类型 | 3D 俯视角生存建造游戏 |
| 核心玩法 | 采集 → 合成 → 建造 → 探索 → 战斗，由电量 / 体温 / 饱食度三条生存指标驱动 |
| 目标平台 | Steam PC（设计基准 1280×720，等比缩放适配任意分辨率） |
| 引擎 / 语言 | Godot 4.7 + GDScript |
| 当前阶段 | Demo —— 核心循环已可跑通，EA 阶段补内容 |

### 1.2 游戏简介

《Lost Land》是一款 3D 俯视角生存建造游戏。玩家可从**冒险家 / 魔女 / 机器人**三位角色中选一位开局，每人拥有一套**专属制作栏**与**专属系统**。三人都在**孤岛中央**醒来，岛上没有救援，玩家需要采集资源、合成工具、搭建营地、探索六大区域，在体温与饥饿的压力下活下去，弄清这座岛为何会被世界遗忘。

**与常规生存游戏的区别：** 三位角色的**基础数值完全相同**（生命 100 / 移速 ×1.0 / 攻击 ×1.0），差别**全部来自系统，不来自数字**。机器人多背一条"电量"线 —— 它是唯一开局就有电量的角色，过冷过热会额外漏电，电量归零会掉血，但电量充沛时也能缓慢自愈；冒险家与魔女默认没有电量，过冷过热直接扣血，回血只能靠吃食物，日后可拾取「动力核心」获得外置电量。同一个岛，三种活法。

### 1.3 开发目标

| 阶段 | 目标 |
|------|------|
| **第一阶段 Demo** | 核心生存循环、采集 / 合成 / 建造、2 种敌人、昼夜、存档 |
| **第二阶段 EA** | 补齐 6 大区域内容、更多敌人、地下遗迹、魔法系统 |
| **第三阶段 完整版** | 完整剧情、多结局 |

## 第二章：游戏整体设计

### 2.1 世界观

#### 2.1.1 背景故事

一场突如其来的海难，把你抛上了这座四面环海的孤岛。

**你在孤岛正中央醒来**，浑身是伤、记忆残缺 —— 只记得自己是个四处漂泊的冒险家，却怎么也想不起是怎么来到这里的。身上一样东西都没剩下：没有工具、没有食物、没有同伴。

岛上有森林、矿区、火山与雪原，却没有救援、没有同类，只有游荡的怪物。你必须先活下来 —— 采集、合成、搭营地，再往岛的深处走，弄清这座岛为什么会被世界遗忘。

> 以上是**冒险家**线的开局叙事。魔女与机器人各有自己的来历，是否共用这段"孤岛醒来"的开场尚待确定（见 7.1）。

#### 2.1.2 世界分层

**表层（已实现）** —— 平面世界，无海拔高差，区域按同心圆环分布（见 4.2）。

```
                        ┌─────────────────────────────────┐
                        │        【失落之岛】表层          │
                        ├─────────────────────────────────┤
                        │  Tier 0 内圈 ─ 草原区（出生·中央）│
                        │  Tier 1 中圈 ─ 丛林 / 矿区 / 沙地 │
                        │  Tier 2 外圈 ─ 火山 / 雪地       │
                        │  岛缘 ─ 沙滩 ├ 外围 ─ 无尽海洋    │
                        └─────────────────────────────────┘
```

**深层（规划中）** —— 机械文明遗迹（地下世界）：遗迹入口 / 废弃工厂 / 能量核心室。Demo 无地下内容。

### 2.2 角色系统

#### 2.2.1 角色阵容总览

**正式角色（3 个）**

| id | 显示名 | 一句话定位 | 核心特色 | 专属系统 | 专属制作栏 |
|----|--------|-----------|---------|---------|-----------|
| `adventurer` | **冒险家** | 靠双手与头脑在荒岛立足的生存者 | 能力待定 | 基础角色（默认无电量） | 求生制作 |
| `witch` | **魔女** | 用草药与符文改写规则的法术使用者 | 制药 / 魔法 | 制药魔法系统（待设计） | 炼药制作 |
| `robot` | **机器人** | 以电力驱动的机械生命，可自我改造 | 电量管理 / 机械改造 | 电量系统 | 机械制作 |

角色 id 会随存档记录，读档时据此还原角色、数值与外观。

**测试角色（3 个，开发期用于验证数值与换装，正式版移除）**

| 显示名 | 特性 | 移速倍率 | 最大生命 | 攻击倍率 |
|--------|------|---------|---------|---------|
| 青铠骑士 | 均衡 | ×1.0 | 100 | ×1.0 |
| 赤铁守卫 | 高血·高攻·慢 | ×0.9 | 130 | ×1.3 |
| 翠影斥候 | 高速·低血 | ×1.25 | 80 | ×0.85 |

#### 2.2.2 通用初始属性

除角色专属系统外，三个正式角色的基础数值完全一致：

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值 | 100 | 三角色一致 |
| 电量 | 100 / 100（仅机器人） | 不随时间消耗；其他角色可拾取「动力核心」获得外置电量（见 3.1.4） |
| 体温 | 30（自然回温目标） | 正常区间 10 ~ 40 |
| 饱食度 | 100 / 100 | 一个游戏日（480 秒）从全饱掉到空 |
| 攻击力 | 10（徒手） | 攻击范围 2.0 米，冷却 0.5 秒；三角色倍率均为 ×1.0 |
| 移动速度 | 5.0 米/秒 | 三角色倍率均为 ×1.0 |

#### 2.2.3 三个正式角色的对比

| 项目 | 冒险家 | 魔女 | 机器人 |
|------|--------|------|--------|
| 生命值 | 100 | 100 | 100 |
| 移速倍率 | ×1.0 | ×1.0 | ×1.0 |
| 攻击倍率 | ×1.0 | ×1.0 | ×1.0 |
| 电量系统 | ✗ 无（拾取动力核心后可获得**外置**电量） | ✗ 同上 | ✓ 有，100/100（**内置**） |
| 生存指标 | 体温 + 饱食度 | 体温 + 饱食度 | 体温 + 饱食度 + 电量 |
| 过冷 / 过热惩罚 | 扣血 ＋（有电量则再）漏电 | 扣血 ＋（有电量则再）漏电 | 扣血 ＋ 漏电 |
| 回血方式 | 吃食物 | 吃食物 | 吃食物 ＋ 电量 > 80 时的自然回血 |
| 开局 | 默认开局角色 | 游戏内解锁（规划中） | 游戏内解锁（规划中） |

**设计意图：三个角色基础数值完全相同 —— 差异全部来自"系统"，不来自"数值"。**

- 好处是不必反复平衡强度：玩家比的是"想要哪种玩法"，不是"谁更强"；加新角色也只需设计系统，不用重算一遍数值表。
- 过冷 / 过热统一为"扣血 ＋（有电量则）漏电"：火山 / 雪地对所有角色都有压力，有电量的角色额外再漏一份电。机器人因此承受双份惩罚，这是它多一条补给线要付的代价。
- 回血出口分两层：**吃食物是所有角色通用的回血手段**；**自然回血是内置电量的专属福利**（仅机器人）。外置电量对人物本体零影响，既不扣血、不减速，也不给回血（见 3.1.1）。

#### 2.2.4 角色专属系统

**① 电量系统（机器人专属）**

| 项目 | 说明 |
|------|------|
| 谁会掉电 | 仅机器人（内置电量）。冒险家 / 魔女默认没有电量，HUD 的 ⚡ 行显示灰色占位 `⚡ --`（见 6.1） |
| 受电量影响的效果 | 低电减速、归零掉血、高电自然回血 —— 只对内置电量（机器人）生效；过冷过热漏电 —— 所有有电量的角色都生效（见 3.1.1） |
| 解锁途径 | 拾取「动力核心」并装入 → 获得**外置**电量（规划中，见 3.1.4） |
| 与角色本身的关系 | 电量只是在身上装了一台外挂设备，不改变角色本身（冒险家依然是冒险家），属于探索奖励 |

**② 魔女的制药魔法系统（待设计）**

已确认魔女拥有专属系统，深度暂未拍板。候选方向：

- 采集草药 / 魔力素材 → 炼药台 → 药剂（回血 / 抗寒 / 抗热 / 增益 / 解毒）
- 符文 / 法阵 → 短时改变地形或天气（与昼夜、温差系统联动）
- 与体温系统互补：药剂作为过冷 / 过热的第二种解法（第一种是熔炉取暖）

> 若做制药，需要新增草药 / 魔力素材两种资源，并为其设计分布、再生与生成规则 —— 这是该系统最大的一块隐性工作量。

**③ 冒险家的特殊能力（待设计）**

候选方向：

- 野外求生：生火、搭简易庇护所、设陷阱（可不依赖工作台）
- 采集大师：资源掉落量 / 采集速度加成
- 用"体力 / 精神"替代电量？（注意与机器人的电量**不要重复**：电量是长期续航，体力应作短期爆发，否则两个角色玩起来一样）

> 在能力确定前，冒险家作为规则的基准角色（无额外负担）可直接开局试玩。

**④ 专属物品的使用权限**

专属物品**只限制"使用"，拾取与携带一律放开** —— 专属物品可能出现在宝箱里被别的角色捡到，捡到不能用已经够让人窝火，捡都不让捡更糟。

| 策略 | 含义 |
|------|------|
| 通用 | 谁都能用 |
| 归属加成 | 谁都能用，归属角色使用时效果加倍（如 ×1.5） |
| 专属锁定 | 只有归属角色能用 |

当前 6 件专属物品：

| 物品 | 归属 | 策略 | 说明 |
|------|------|------|------|
| 草药绷带 | 冒险家 | 通用 | 谁都能用来回血 |
| 干粮 | 冒险家 | 通用 | 同上 |
| 治疗药剂 | 魔女 | 通用 | 同上 |
| 活力药剂 | 魔女 | 通用 | 同上 |
| 高容量电芯 | 机器人 | 专属锁定 | 只有机器人能用（+60 电量），别人用了没有意义 |
| 维修包 | 机器人 | 归属加成 ×1.5 | 谁都能用来回血，机器人使用效果 ×1.5 |

> 完全锁死会让玩家"捡到一件好东西却只能扔掉"，体验很差；完全不差异又会让"专属"失去意义 —— 折中做法是**基础功能通用、加成专属**。
> 专属**装备**的权限（武器 / 护甲 / 工具槽）尚未纳入同一套规则，规划中。

**⑤ 角色解锁策略**

| 阶段 | 规则 |
|------|------|
| 正式目标 | 冒险家为开局角色；魔女 / 机器人作为后续奖励，通过游戏内途径解锁（与遗迹探索天然结合） |
| 开发 / Demo 期 | 三个角色全部开放、任选开局，便于测试与试玩 |

> 两者是"目标态"与"当前态"的关系，正式发布时收紧为"冒险家开局 + 解锁制"。

#### 2.2.5 角色专属制作栏

每个角色除通用分类（材料 / 工具 / 武器 / 护甲 / 建筑）外，还拥有一栏**专属标签**，只在对应角色的合成界面出现。

| 专属栏 | 归属 | 配方 | 说明 |
|--------|------|------|------|
| 求生 | 冒险家 | 草药绷带（草 ×5 + 木棍 ×1，回 25 生命）、干粮（浆果 ×3 + 草 ×2，+40 饱食 +15 生命） | 冒险家没有自然回血，靠自制补给续命 |
| 炼药 | 魔女 | 治疗药剂（浆果 ×5 + 史莱姆凝胶 ×2，回 50 生命）、活力药剂（浆果 ×3 + 史莱姆凝胶 ×3 + 草 ×2，+60 饱食 +20 生命） | 深度待定（见 2.2.4-②） |
| 机械 | 机器人 | 高容量电芯（电池 ×2 + 铁锭 ×1，+60 电量）、维修包（铁锭 ×2 + 木棍 ×2，回 40 生命） | 唯一有电量的角色，专属栏全是能量与自检维修 |

> 这 6 条是**占位配方**，待冒险家能力与魔女制药定稿后替换，机制不变。
> **专属制作站（规划中）**：炼药台 / 装配台 —— 谁都能放置，但只有对应角色能出配方。当前专属配方无需制作站。

#### 2.2.6 角色选择与换装

## 第三章：核心系统详细策划

### 3.1 电量系统（机器人专属）

电量是**机器人**维持运转的第一资源，**不随时间自动消耗**。机器人以电力驱动，电量是它的固有属性，开局自带，不需要任何道具。

冒险家 / 魔女默认没有电量 —— HUD 的 ⚡ 行是灰色占位，下列"影响人物本体"的效果（低电减速、归零掉血、高电回血）一律不生效。

#### 3.1.1 两种电量语义（内置 / 外置）

**分界线是"电量能否影响人物本体"。** 外置电量不是"机器人的电量换个皮"，它对人物本体**零影响**。

| 效果 | 内置（机器人） | 外置（冒险家 / 魔女装核心） |
|------|---------------|---------------------------|
| 过冷 / 过热额外漏电 | ✅ | ✅（环境在耗这块电池） |
| 电量归零掉血（-1 HP/秒） | ✅ | ❌ |
| 低电（≤10）减速 ×0.7 | ✅ | ❌ |
| 电量 > 80 且吃饱缓慢回血（+5 HP/分） | ✅ | ❌ |
| 能否关闭 | ❌（不可拆除） | ✅（可拆，拆除后电量清零） |
| 回血出口 | 吃食物 ＋ 自然回血 | 只有吃食物 |

- 两种语义唯一共有的是**过冷 / 过热漏电**：环境在耗这块电池，与电池装在哪无关。
- 外置电量保留的意义是"耗电交互可用"（消耗电量的配方与设备）。
- 判断某个角色当前有没有电量，要看**运行时状态**（核心可装可拆），不能只看角色的开局设定。

#### 3.1.2 参数

| 参数 | 数值 |
|------|------|
| 最大 / 初始电量 | 100 / 100 |
| 自动消耗 | 无 |
| 特殊消耗 | 过冷或过热时每秒 -0.5（见 3.2.2） |
| 补充 | 电池 +10（可合成）；大型电池 +50（规划中） |

> **「动力核心」与「电池」是两回事**：核心用来**解锁电量**，电池用来**补充电量**。

#### 3.1.3 电量状态影响（仅内置电量 / 机器人）

| 电量范围 | 状态 | 影响 |
|---------|------|------|
| > 80 | 充沛 | 生命值自然恢复 **+5 HP/分钟**（需同时满足"不饿"，见 3.3.2） |
| 11 ~ 80 | 正常 | 无 |
| ≤ 10 | 低电量 | 移动速度 **×0.7** |
| = 0 | 濒危 | 每秒 **-1 生命值** |

> 自然回血的完整条件是**电量 > 80 且 饱食度 > 20 且未满血**，按累积器结算整数 HP。外置电量既不回血也不掉血，回血只能靠吃食物（见 3.3.2）。

#### 3.1.4 动力核心（电量解锁道具 · 规划中）

动力核心是一件**探索途中的拾取物** —— 来历不明的遗物，装到谁身上，谁就有了电量。

| 项目 | 内容 |
|------|------|
| 类型 | 可入包物品；不是装备、不是消耗品 |
| 获取 | 探索途中拾取。拟定投放点：**地下遗迹**的台座 / 战利品箱；具体位置与是否多处投放待设计 |
| 作用 | 装入 → 获得**外置**电量 100/100（语义见 3.1.1：不掉血 / 不减速 / 不回血，只保留漏电与耗电交互） |
| 对机器人 | 机器人开局自带电量，不需要核心（是否另有"扩容 / 备用能源"用途待定） |
| 可否拆除 | 可以，装拆双向 —— 解锁是一次主动的风险交易，而非单向陷阱 |

> **设计动机：** 电量作为**探索的回报**出现，与"往岛的深处走"同向；三个人物的差异能一直保留到玩家真正做出选择为止；核心的来历则成为悬念，不必在开场硬解释。

### 3.2 体温系统

体温反映角色的冷热状态，由所处地形与热源驱动。

#### 3.2.1 参数

| 参数 | 数值 |
|------|------|
| 正常区间 | 10 ~ 40（无影响） |
| 过冷区间 | -10 ~ 10 |
| 过热区间 | 40 ~ 80 |
| 绝对值范围 | -100 ~ 100 |
| 自然回温目标 / 速率 | 趋向 30，**10/分钟** |

#### 3.2.2 体温影响

| 体温区间 | 所有角色 | 有电量时额外 |
|---------|---------|-------------|
| 10 ~ 40（正常） | 无 | 无 |
| -10 ~ 10（过冷） | 每秒 **-0.5 生命值** | 每秒 **-0.5 电量** |
| 40 ~ 80（过热） | 每秒 **-0.5 生命值** | 每秒 **-0.5 电量** |
| < -10 或 > 80 | 持续扣血（暂无额外惩罚） | 持续漏电（暂无额外惩罚） |

- 温度惩罚**先扣血**（对所有角色生效），**再额外漏电**（对所有有电量的角色生效，含外置）。火山 / 雪地对谁都有压力，不会因为没有电量就白送难度；机器人则双份承担。
- 选择"扣血"而不是"减速"，是因为减速只是拖慢节奏、不会真的逼玩家撤退；扣血会直接把"带够补给 / 早点回营地"变成硬需求 —— 与之配套的回血出口就是吃食物（见 3.3.2）。

#### 3.2.3 各区域体温变化

| 区域 | 体温变化 | 说明 |
|------|---------|------|
| 草原区 / 丛林区 / 矿区 / 沙地区 / 沙滩 | 趋向 30，10/分钟 | 自然回温 |
| 火山区 | **+15/分钟** | 持续升温，久留必过热 |
| 雪地区 | **-15/分钟** | 持续降温，久留必过冷 |
| 熔炉附近（5 米内） | 趋向 **35 度**，20/分钟 | 热源**压过**地形影响，雪地里烤火体温稳定在约 34 度 |
| 地下遗迹 | — | Demo 无地下区域（规划中） |

### 3.3 饱食度系统

角色和常人一样需要进食补充体力，所以会饿：饿到阈值会减速、掉血，而**吃食物是回血的主要手段** —— 于是吃饭这件事变得和打架一样重要。

#### 3.3.1 参数

| 参数 | 数值 |
|------|------|
| 最大 / 初始饱食度 | 100 / 100 |
| 消耗速率 | **100 / 480 每秒** —— 一个游戏日（480 秒）从全饱掉到空 |
| 饥饿阈值 | ≤ 20 |
| 温饱阈值 | ≥ 80 |
| 饥饿惩罚 | 移动速度 **×0.9**，且**停止自然回血** |
| 归零惩罚 | 每秒 **-0.5 生命值**（比电量归零的 -1.0 温和，留出找食物的时间） |

#### 3.3.2 回补方式（饱食度 / 生命值）

| 方式 | 效果 | 说明 |
|------|------|------|
| 浆果 | **+25 饱食度** ＋ **+10 生命值** | 空手可采，浆果丛 240 秒再生 |

- **吃食物 = 补饱食度 且 回血**，两者一起结算，是**所有角色通用**的回血手段。
- **只有机器人**另有"电量 > 80 且吃饱"的缓慢自然回血（+5 HP/分钟）作为额外福利；外置电量不回血（见 3.1.1）。
- **防滥用门槛：饱食度已满时整次进食作废**（含回血），判断在结算前 —— 否则"满着肚子啃浆果回血"会抹平战斗与环境的风险。
- 一条食物可以同时给多个属性加成（例如浆果既补饱食度也回血）。

#### 3.3.3 移速惩罚合并规则

低电量与饥饿**不相乘**，取更狠的那个 —— 相乘会让残血玩家几乎走不动路。

| 状态 | 移速乘数 |
|------|---------|
| 正常 | ×1.0 |
| 仅饥饿 | ×0.9 |
| 仅低电量（内置） | ×0.7 |
| 又饿又没电（内置） | ×0.7（取小值，不是 0.63） |

> 外置电量不参与低电减速（见 3.1.1）。

### 3.4 生命、死亡与复活

#### 3.4.1 伤害计算

```
实际伤害 = max(1, 敌方攻击力 - 玩家防御力)
```

护甲可以减免伤害，但**至少掉 1 点**，避免堆防御后完全无敌。

#### 3.4.2 死亡条件

| 死因 | 判定 |
|------|------|
| 生命值归零 | 被敌人打死 / 电量归零持续掉血 / 饥饿归零持续掉血 / 过冷过热持续扣血 |
| 落水 | 走进海洋 —— 海水**没有碰撞体**，踩上去就是自由落体，坠到一定深度判定溺亡 |

#### 3.4.3 死亡 → 复活流程

```
死亡 → 画面转灰暗 + 屏幕底部中央 5 秒倒计时
     → 倒计时结束 / 点击"复活"按钮 → 原地满血复活（体征重置、画面恢复正常、镜头直接对准角色）
```

- 死亡流程不会重复触发倒计时。
- 敌人目标判定统一为"玩家是否活着"：玩家一死，史莱姆与无人机**立刻放弃追击 / 停火**，复活后自动重新锁定。
- 复活时生命、体温、饱食度重置；**没装动力核心的角色不会因为复活而凭空满电**。
- 镜头在复活瞬间直接落到角色身上，不播放移动过程。

**画面滤镜**

| 滤镜 | 触发 |
|------|------|
| 死亡 | 画面转灰暗（死亡期间常驻） |
| 低血量 | 血量过低时常驻 |
| 受击 | 受击瞬间的短促脉冲 |
| 过热 / 过冷 | 预留（规划中） |

> 滤镜与昼夜系统共用同一个环境效果，染色 / 暗角类效果尚未启用。

| 掉落物 | 电池（20%） |
| 出没区域 | 矿区、地下遗迹（规划中） |

> 无人机**没有碰撞体积**：玩家可以穿过它，它也不被地形和建筑阻挡 —— 高度完全由悬停逻辑控制，只靠一个命中盒被玩家打到。
>
> 弹幕是**直线平射**：只会沿水平方向飞，命中玩家、撞上地形、或飞满射程即消失。因此它**打不到侧面**——玩家横向走位（或绕到侧面）就能躲开，不存在"追着人拐弯"的情况。

#### 3.9.4 敌人受击与死亡

- 伤害判定：敌人身上挂命中盒，玩家的攻击范围内有命中盒即造成伤害。
- 敌人死亡：生成掉落物，存档不再记录（读档不会复活）。

#### 3.9.5 出生点测试敌人（开发期验证用）

- 地图生成时在出生点**东 9 米**放一只史莱姆、**西 9 米**放一架无人机。
- 新开局和读档都会生成，存亡由存档判定。
- 测试无人机不巡航矿区。

### 3.10 昼夜系统

#### 3.10.1 时间周期

| 参数 | 数值 |
|------|------|
| 一天长度 | **480 秒**（8 分钟真实时间） |
| 开局时刻 | 早上 8:00 |
| 白天 | **7:00 ~ 18:00** |
| 夜晚 | 18:00 ~ 次日 7:00 |

#### 3.10.2 昼夜表现

- 太阳 / 月亮两盏方向光随时间升落（正弦俯仰角 + 东升西落方位角）。
- 天空背景色、环境光颜色与强度按关键帧渐变：深夜（冷蓝、压暗）→ 日出（橙）→ 正午（暖白）→ 黄昏（红橙）→ 深夜。
- HUD 顶部时钟显示当前天数与时刻。

#### 3.10.3 昼夜玩法影响

| 影响因素 | 状态 |
|---------|------|
| 视觉明暗 | 已实现（夜间环境光压到约 1/3） |
| 夜行敌人 / 夜间降温 | 规划中 —— 等敌人扩充时挂上 |

### 3.11 存档系统

| 项目 | 内容 |
|------|------|
| 槽位 | **不限量**，主菜单直接读目录展示（存档名、天数、角色） |
| 保存时机 | 暂停菜单手动保存；返回主菜单 / 退出 / 无槽时自动保存 |

存档内容为**全量**：

| 段 | 内容 |
|----|------|
| 地形 | **整座岛的地皮**（1600×1600 逐格记录，压缩后约 10 KB） |
| 世界 | 天数 / 时刻、**地图种子**、全部资源状态（含视野外的）、全部敌人、地面掉落物、全部建筑（含储物箱内容） |
| 角色 | 角色 id、位置、生命、电量、体温、饱食度、背包、装备三槽 |
| 相机 | 朝向与缩放 |

- **地形是"存下来"的，不是"算出来"的**：存档直接带上地皮数据，读档时按存档还原，因此**后续更新改动地图生成规则也不会让老存档的岛变形**（否则建筑会落水、资源会悬空）。代价约 10 KB/档（现有存档约 476 KB）。
- **地图种子仍然记录**，但身份是元数据（这张岛怎么来的）：用于复现、调试，以及将来"重新生成未探索区域"这类功能。
- **已击杀的敌人不会复活**：存档里没有的敌人 = 已被击杀。
- 读档时资源的过程态（采集中 / 再生中）统一归一为"已采集"，避免读到没有计时器的中间状态。
- 每个存档都带地形自检信息（哈希）与格式版本号：地形数据损坏、或存档来自更新版本时，会明确提示而不是静默出错。老存档（无地形段）仍可读取，按种子重算地形。

## 第五章：主线与 Boss 战（规划中）

> 两条区域主线：沙地区的**沙虫**与丛林区的**巨鸟**。两条线的节奏完全一样 —— **遭遇 → 打不过可以撤 → 击退 → 打开一片新区域**；区别只在收尾：沙虫线把玩家送进地下的实验室，巨鸟线把玩家送上巨树。

### 5.1 沙地区主线：沙虫

#### 5.1.1 沙虫巢穴

| 项目 | 内容 |
|------|------|
| 位置 | 沙地区 |
| 外观 | 沙地上的一块**四边形凹坑，被沙子覆盖**（贴图规划中） |
| 状态 | **完好** / **坍塌** |

#### 5.1.2 第一阶段：地表战

- 玩家**靠近巢穴并停留一段时间**后，一只**巨大的沙虫**从巢穴中钻出，主动攻击玩家。
- 玩家若及时远离、让沙虫**丢失目标**，它会**回到巢穴并补满血量** —— 靠反复消耗磨死它是行不通的，必须一次打完。
- 沙虫**即将死亡**时：
  - 掉落**战利品**（内容规划中）
  - **保留最后 1 点生命、进入无敌状态**，逃回巢穴
  - **巢穴坍塌**

#### 5.1.3 第二阶段：坍塌巢穴与实验室

- **巢穴完好时进不去**，只有坍塌后才能进入 —— 这本身就是一道进度门。
- 穿过巢穴，玩家来到一所**神秘的实验室**（房间内容规划中）。
- 实验室的终点，是那条**没被杀死的沙虫** —— 它已被改造成**机械沙虫**。
- 机械沙虫同样可以脱离：玩家**逃出房间**即可让它丢失目标，但它会**回满血**。
- 击败机械沙虫，获得**专属战利品**（内容规划中）。

### 5.2 丛林区主线：巨鸟

#### 5.2.1 巨树与盘旋的巨鸟

| 项目 | 内容 |
|------|------|
| 巨树 | 丛林区内一棵**巨大的树**（位置与贴图规划中） |
| 巨鸟 | 绕着巨树**盘旋**，尚未落地（名称规划中） |
| 地面提示 | 巨鸟在**地面投下影子**，提示"它就在你头顶" |

#### 5.2.2 第一阶段：地面战

- 玩家**试图靠近巨树**时，巨鸟会**降落**并与玩家战斗。
- 玩家远离、让巨鸟**丢失目标**后，它会飞回树上并**回满血**。
- 巨鸟**即将落败**时：
  - **吐出一颗特殊种子**
  - 掉落**羽毛**（用途规划中）
  - **保留最后 1 点生命、进入无敌状态**，**飞回树上**

#### 5.2.3 第二阶段：种子与巨树之上

- 把**特殊种子种在巨树旁**，**几天之后**（按游戏内天数计）种子长出**藤蔓**，环绕着巨树。
- 玩家**攀爬藤蔓**登上巨树，抵达**巨树之上的新区域**（内容规划中）。

### 5.3 主线设计要点

| 要点 | 说明 |
|------|------|
| **Boss 打不死** | 两条主线的 Boss 在濒死时都不会死，而是保留最后 1 点生命逃走 —— "打赢"不等于"打死"，而是让它退走、打开下一层 |
| **打不过可以撤** | 两个 Boss 都允许玩家脱离战斗，逃开即回满血；但**进度不会白送** |
| **先打后开** | 巢穴要**先击退沙虫**才会坍塌、才进得去；藤蔓要**先击退巨鸟**拿到种子才长得出来 —— 玩家必须先赢一场，才能打开新区域 |
| **两条线各自独立** | 一条在沙地、一条在丛林，互不依赖，玩家可自行决定先后（规划中） |
| **Boss 数值** | 血量、伤害、攻击方式与阶段技能均**规划中** |
