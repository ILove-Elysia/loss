# 海岛地图生成器：拆分为多节点 + 多脚本 + 资源化配置

## Context（背景）
当前实现是一个 602 行的单脚本 `main.gd`，挂在 `Main.tscn` 的 Control 根节点上，包揽了岛屿生成、点位放置、BFS 扩散、像素渲染、动画与全部 UI 构建。所有参数硬编码在脚本里，难以单独查看与调整。

目标：按生成阶段拆分为多个**节点 + 脚本**，把颜色/形状参数抽成可保存、可在检视面板切换预设的 **Resource（.tres）**，并把全部 UI 节点写进 **Main.tscn** 以便可视化编辑。功能与约束逻辑保持不变（已验证的行为不回归）。

## 架构总览

### 场景树（Main.tscn，全部节点可视化）
```
Main (Control)  [main.gd — 协调者]
├── Background (ColorRect)              深色背景，full rect
├── MarginContainer                     full rect, margin 16
│   └── VBoxContainer                   separation 10
│       ├── TitleLabel (Label)          标题 font 24 居中
│       ├── SubtitleLabel (Label)       副标题 font 13 暗色居中
│       └── ContentRow (HBoxContainer)  separation 22 居中
│           ├── MapPanel (PanelContainer) 边框 StyleBoxFlat
│           │   └── MapTexture (TextureRect) 600×600, nearest, expand_ignore, stretch_scale
│           └── SidePanel (VBoxContainer)   separation 12, v_shrink_center
│               ├── LegendPanel (Panel) [legend_panel.gd]  palette=default_palette.tres
│               ├── RegenButton (Button)  “重新生成地图” 240×50 font16
│               ├── StatusLabel (Label)   居中 font13
│               └── InfoLabel (Label)     说明 font12 暗色
├── IslandGenerator (Node) [island_generator.gd]  shape=default_shape.tres
├── TerrainPlacer (Node)   [terrain_placer.gd]
├── TerrainDiffuser (Node) [terrain_diffuser.gd]
└── MapRenderer (Node)     [map_renderer.gd]       palette=default_palette.tres
```
- 4 个生成功能节点作为 Main 直接子节点，可在编辑器选中并调 @export。
- `MapRenderer.texture_rect` 由 `main.gd` 在 `_ready` 用 `$.../MapTexture` 显式赋值（比 .tscn NodePath 更稳，仅一行）。

### 脚本与资源文件（res://map_gen/）
| 文件 | 类型 | 职责 |
|---|---|---|
| `terrain_defs.gd` | class_name TerrainDefs (RefCounted) | 共享常量：W/H/CX/CY/DISP、地形 id 枚举、`idx()` 静态函数 |
| `map_data.gd` | class_name MapData (RefCounted) | 管线数据容器：island/points/grid/dist/max_dist |
| `terrain_palette.gd` | class_name TerrainPalette (Resource) | @export：ocean_color、base_color、terrain_colors[6]、terrain_names[6]、terrain_danger[6] |
| `default_palette.tres` | TerrainPalette 资源 | 引用脚本、用脚本默认值（当前配色） |
| `island_shape.gd` | class_name IslandShape (Resource) | @export：base_radius、amp1/2/3、freq1/2/3、ellipse_jitter |
| `default_shape.tres` | IslandShape 资源 | 引用脚本、用脚本默认值 |
| `island_generator.gd` | IslandGenerator (Node) | @export shape；`generate(data, rng)` 生成岛屿掩膜 |
| `terrain_placer.gd` | TerrainPlacer (Node) | @export snow_min/max_radius、opposite_jitter；`place(data, rng)` 放 6 点（含距离约束） |
| `terrain_diffuser.gd` | TerrainDiffuser (Node) | @export use_8_neighbor；`diffuse(data)` 多源 BFS |
| `map_renderer.gd` | MapRenderer (Node) | @export palette、anim_min/max_duration、noise_amplitude；`render_ocean()`/`prepare(data)`/`animate(cb)`/`cancel()` |
| `legend_panel.gd` | LegendPanel (Panel) | @export palette；`_ready` 依据 palette 自动构建图例行 |
| `main.gd`（根目录） | Control | 协调者：连按钮、串管线、更新状态文本 |

### 数据流（管线）
`main.regenerate()` → `renderer.render_ocean()` → 等 0.25s →
`island_generator.generate(data, rng)` → `terrain_placer.place(data, rng)` → `terrain_diffuser.diffuse(data)` → `renderer.prepare(data)`（显示裸岛）→ 等 0.25s → `renderer.animate(完成回调)`。
`MapData` 实例沿管线传递；颜色统一来自 `TerrainPalette`，渲染器与图例共享同一 `.tres` 实例（preload 缓存）。

### 生成批次防冲突
`main._gen_id` 递增；`renderer.cancel()` 杀旧 tween；await 处用 `gid != _gen_id` 守卫。与现有实现一致。

## 关键实现要点
- 逻辑直接搬迁自当前 `main.gd` 对应函数，**算法与约束不变**（含上一轮的距离 OR 约束）。
- 渲染器把噪点生成移入自身 `_build_final`（`_hash2`），`noise_amplitude` 控制强度；动画仍用「按 dist 桶排序 + 每帧只写新增格」的增量策略。
- Resource 脚本的 @export 默认值即当前数值；`.tres` 仅 `script = ExtResource(...)` 一行，默认值由脚本提供，避免手写 `Array[Color]` 序列化。
- `Main.tscn`：`@export` 资源用 `ExtResource` 指向 `.tres`；theme override（font_size/separation/margin/color/stylebox）以属性形式写入；`load_steps` = ext_resource 数 +1。
