## 📚 核心概念

Godot 使用**碰撞层（Layer）**和**碰撞掩码（Mask）**系统：

```
collision_layer = 我站在哪个层（我是什么）
collision_mask  = 我能碰到哪些层（我能和什么碰撞）
```

### 默认值
- `collision_layer = 1`（所有物体默认在第 1 层）
- `collision_mask = 1`（能检测第 1 层）

## 🔧 推荐设置方案

### 方案 1：使用 Godot 编辑器设置（推荐）

在编辑器中操作：

**1. 设置 Player（Physics 节点）**
- 选中 `player.tscn` 中的 `Physics` 节点
- 在右侧 Inspector 中找到 **CollisionObject3D** 部分
- 设置 `collision_layer` = `1`（角色层）
- 设置 `collision_mask` = `1`（能碰到地面）

**2. 设置 Ground（地面）**
- 选中 `test.tscn` 中的 `Ground` 节点
- 设置 `collision_layer` = `1`（地面层）
- 设置 `collision_mask` = `1`（保持默认）

### 方案 2：代码中设置

在 `physics.gd` 的 `_ready()` 函数中添加：

```gdscript
func _ready():
	# 设置碰撞层：角色在第 1 层
	collision_layer = 1
	# 设置碰撞掩码：只检测第 1 层（地面）
	collision_mask = 1
	
	up_direction = Vector3.UP
	spr.play("idle")
```

## 📋 常用层规划（建议）

```
Layer 1 = 地面/环境 (Ground)
Layer 2 = 玩家角色 (Player)  
Layer 3 = 敌人 (Enemy)
Layer 4 = 可拾取物品 (Pickup)
```
